# JSON contracts — exam_engine (Member 2 → Members 1 & 3)

All functions return plain JSON-serialisable dicts. Real samples generated by running the code on the
**synthetic** test course are in `docs/exam_examples/` (`python scripts/generate_exam_examples.py`).
Optional fields are `null` (never missing) unless noted. Scores shown to students are always
accompanied by a plain-language field (`why`, `explanation`, `recommendation`, `reasons`).

## 0. Input agreed with Member 1 (chunk / page record)

```json
{"document_id": "doc_001", "document_name": "Past Paper 2025.pdf", "page_number": 3, "text": "Extracted academic content"}
```

The year of a paper is parsed from `document_name` (first 19xx/20xx). Embedder contract (Member 1's shared service):
an object with `encode(list[str]) -> 2-D array` (or `embed(...)`, or a plain callable); optional `kind` ("dense" default) and `prepare(texts)`.
LLM contract (optional): `llm(prompt: str) -> str` (a local model; must return JSON for quizzes).

## 1. Past-paper analysis — `ExamEngine.analyze_past_papers(chunks, syllabus_topics=None)`

```
{
  "questions": [ Question, ... ],
  "similar_question_groups": SimilarityResult,
  "repeated_questions": [ Group, ... ],          // groups with paper_count >= 2
  "topic_frequency": TopicFrequency,             // vs syllabus_topics if given, else discovered
  "important_topics": [ ImportantTopic, ... ],
  "discovered_topic_frequency": TopicFrequency   // only when syllabus_topics was given
}
```

**Question** — `question_id, number ("4a"), text, marks|null, section, question_type
(define|explain|compare|list|numerical|design|short_note|other), document_id, document_name, page_number, year|null, confidence (0-1)`

**SimilarityResult** — `embedder ("dense"|"lexical"), threshold, total_questions, total_papers, groups[], unique_questions[], summary{repeated_groups, questions_in_groups, unique_question_count}`

**Group** — `group_id, representative, size, paper_count, papers[], years[], repeated (bool), match_type ("exact"|"near_duplicate"|"reworded"), avg_similarity, min_similarity, shared_key_terms[], members[{question fields..., similarity_to_representative}], explanation`

## 2. Important topics — `topic_frequency` / `important_topics`

**TopicFrequency** — `total_questions, total_papers, topic_source, scoring_basis, notes[], unmatched_questions[]` (syllabus mode only), and `topics[]`:

`rank, topic, importance_score (0-100), importance_label (High|Medium|Low), confidence (low|medium|high), paper_count, papers[], years[], question_count, total_marks|null, share_of_questions_pct, share_of_marks_pct|null, keywords[], question_types{}, example_questions[], question_ids[], recurring, one_off, why`

**ImportantTopic** (slim list for charts) — `rank, topic, importance_label, importance_score, paper_count, question_count, years, keywords, why, confidence`

Notes: a question that mentions several discovered topics counts toward each (shares may exceed 100 %). With one paper
`confidence` is `"low"` and the score reflects exam weight only. Display `why`, not the number alone.

`ExamEngine.lecture_topics(chunks)` → `[{topic, mentions, documents:[{document, pages[]}]}]`

## 3. Syllabus coverage — `ExamEngine.syllabus_coverage(syllabus_topics, lecture_chunks)`

`syllabus_topics`: `["Name", ...]` or `[{"name","subtopics":[...],"description"}]` (`parse_syllabus_text(text)` builds these from a plain syllabus).

```
{ "embedder", "thresholds": {"covered": 0.65, "partial": 0.35|0.40},
  "summary": {total_topics, covered, partially_covered, not_covered, coverage_pct, gaps[]},
  "topics": [{
    "topic", "status": "Covered"|"Partially covered"|"Not covered",
    "document"|null, "document_id"|null, "pages": [4,5], "evidence_score": 0-1,
    "semantic_similarity", "term_coverage", "matched_terms[]", "missing_terms[]",
    "other_documents": [{"document","pages"}], "evidence_snippet",
    "closest_material": {"document","page"}|null,       // only for Not covered
    "subtopics": [{"subtopic","status","evidence_score","document","page"}],
    "explanation" }] }
```

## 4. Quiz — `make_quiz(context_chunks, topic, n_questions)` and `grade(quiz, answers)`

```
{ "topic", "generation_report": {requested, generated, from_llm, from_extractive, llm_rejected, llm_rejection_reasons[], notes[]},
  "questions": [{
    "question_id", "topic", "question",
    "options": [{"key":"A","text":""}, ... 4 items], "correct_option":"B", "correct_answer", "explanation",
    "difficulty": "basic"|"intermediate"|"advanced",
    "source": {"document_id","document_name","page_number","evidence"},
    "generation_method": "extractive"|"llm" }] }
```
`generated` can be lower than `requested`: unsupported questions are deliberately not created.

**Quiz results** — `grade(quiz, {"question_id": "B"})`:
`{topic, total, correct, incorrect, accuracy, results:[{question_id, topic, difficulty, selected_option|null, correct_option, is_correct, explanation, source}]}`

## 5. Weak topics — `weak_topics(quiz_results, min_attempts=3, weak_below=0.6, strong_from=0.8, prerequisites=None, topic_importance=None)`

Input: list of graded quiz results and/or flat records `{topic, is_correct, question_id?, difficulty?, timestamp?, source?}`.

```
{ "overall": {attempted, correct, incorrect, accuracy|null},
  "weak_topics": ["Networking"], "strong_topics": [...], "revision_order": ["TCP basics", "TCP congestion control"],
  "settings": {...},
  "topics": [{ "topic", "attempted", "correct", "incorrect", "accuracy", "smoothed_accuracy",
    "status": "weak"|"developing"|"strong"|"not_enough_data", "trend": "improving"|"declining"|"steady"|null,
    "accuracy_by_difficulty": {"basic": {attempted, correct, accuracy}},
    "repeatedly_missed_questions": [{"question_id","times_wrong"}],
    "revision_priority": 0-100, "priority_label", "review_pointers": [{"document","page"}],
    "revise_after": [prerequisite topics], "recommendation" }] }
```

## 6. Revision plan — `revision_plan({"topic_frequency", "syllabus_coverage", "weak_topics", "progress"}, days, minutes_per_day)`

Every key of `analysis_results` is optional. `progress`: `{"Topic": {"minutes_done": 30}}`.

```
{ "summary": {topics_in_plan, days, minutes_per_day, signals_used[], headline},
  "notes": ["Plan built without: ..."],
  "priority_topics": [{ "rank", "topic", "aliases[]", "priority_score": 0-100, "priority_label",
      "suggested_minutes", "minutes_done",
      "signals": {"exam_importance": 0-1|null, "weakness": 0-1|null, "coverage_gap": 0-1|null},
      "not_seen_in_past_papers": bool, "reasons": [str], "actions": [str], "details": {...} }],
  "schedule": [{"day": 1, "minutes": 90, "sessions": [{"topic","minutes"}]}] }
```
